# MerchantPay V0.7 — Payment Recording & Balance Management

Built on the verified V0.6.3.1 invoice baseline.

## Included
- Record manual payments against an invoice.
- Supported methods: Cash, Mobile Money, Bank Transfer, Other.
- Optional payment/receipt reference.
- Multiple payments per invoice.
- Payment history on each invoice.
- Automatic paid amount and outstanding balance.
- Automatic invoice status updates to PARTIALLY_PAID or PAID when payments are recorded.
- Prevent payments larger than the outstanding balance.
- Cancelled invoices cannot receive payments.
- Merchant-scoped payment access and invoice ownership checks.
- Dedicated Payments page with direct navigation.
- No payment gateway or payment-processing integration is introduced.

## Database
The V0.6.3.1 schema already contained the Payment model and Invoice.payments relation, so no new Prisma model was required for this milestone.

After extracting the ZIP on a development machine:
1. Run `npm install`.
2. Run `npx prisma generate`.
3. Run `npm run db:push` if the existing database has not yet received the Payment table/schema.
4. Run `npm run dev`.

## Important behavior
Payments are recorded as completed merchant records. MerchantPay does not move money, connect to a payment provider, or verify a transaction with a third-party gateway in V0.7.
