# MerchantPay V0.8 — Merchant Operations & Subscription Foundation

## Subscription tiers
- Basic: Free, maximum 5 invoices
- Plus: UGX 25,000, maximum 50 invoices
- Pro: UGX 58,000, maximum 200 invoices
- Platinum: UGX 102,000, unlimited invoices

Invoice creation limits are enforced server-side. Existing financial functionality from V0.7.1 is preserved.

## Business settings
- Business name, phone and currency editing
- PNG/JPG/WebP logo upload, replacement and removal
- Dashboard logo display
- Logo is stored as a data URL in the database for this lightweight milestone; external object storage can replace this later.

## Subscription activation note
MerchantPay does not process subscription payments in V0.8. Paid-plan activation is intentionally left for the subscription/admin milestone, so selecting a paid tier does not falsely grant paid access before payment is confirmed.

## Dependencies
No new npm dependencies were added in V0.8.
