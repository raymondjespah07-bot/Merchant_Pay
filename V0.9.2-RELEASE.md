# MerchantPay v0.9.2
- Account-specific light/dark appearance and accent color stored on the User record.
- Theme initializes from the logged-in account, preventing cross-account theme leakage and light-mode flash after login.
- Admin feedback inbox supports unread/read/all filtering, unread badges and automatic read marking.
- Admin can open merchant profiles from feedback and overview, with a direct path back to feedback.
- Admin overview has merchant search.

## Database update
Run `npx prisma db push` after `npm install` to add `theme` and `appearance` columns to User.
No new npm packages are required.
