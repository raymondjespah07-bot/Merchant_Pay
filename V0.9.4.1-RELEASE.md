# MerchantPay v0.9.4.1
Admin feedback/profile authenticity, merchant-specific feedback history, Control Center drill-downs, announcement delivery, account-specific preferences loading, password change, invoice allowance modal, and non-expired plan switching.

Run after extraction:
1. npm install
2. npx prisma db push
3. npm run db:generate
4. npm run dev

No new npm packages are required.
