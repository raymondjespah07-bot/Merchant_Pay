# MerchantPay v0.9.4.3

## Fixed
- Dark-mode contrast for Merchant account controls and status pills.
- Control cards now use theme variables instead of a hard-coded white fallback.
- Additional theme-aware surfaces, text, inputs, customer details, modals and messages.
- Announcements endpoint now handles a temporarily unavailable database without throwing repeated Prisma stack traces.
- Announcement polling reduced from 30 seconds to 10 seconds.
- Admin accounts are excluded from normal merchant business lists and Control Center platform counts.

## Added
- Super Admin **Subscription pricing & Test Mode** panel in Control Center.
- Separate Live and Test prices for all subscription tiers.
- Enable Test Mode / switch back to Live Mode controls.
- Confirmation before changing mode.
- Every Test/Live mode switch is automatically recorded in `AdminAuditLog`.

## Database
Run `npx prisma db push` after installing dependencies so `PlatformSettings` and `AdminAuditLog` exist.
