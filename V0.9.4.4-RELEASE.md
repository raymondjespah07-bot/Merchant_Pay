# MerchantPay v0.9.4.4

## Added
- Merchant account preference refresh every 2 seconds, beginning immediately on login/page load.
- Announcement refresh every 2 seconds, beginning immediately and continuing while logged in.
- Separate Live and Test subscription expiration periods in minutes.
- Test Mode uses the Test expiration period; Live Mode uses the Live expiration period.
- Exact plan-change timestamp, expiry timestamp and configured period recorded for every merchant plan change.
- Existing active timed subscriptions retain their expiry during a free upgrade/downgrade.
- Admin overview shows the last plan-change time.
- Super Admin Audit Log page is available from Admin navigation.
- Expiration period changes are automatically recorded in the audit log.

## Database update
Run:
```
npx prisma generate
npx prisma db push
```
Then restart:
```
npm run dev
```
