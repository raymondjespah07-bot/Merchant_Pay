# MerchantPay v0.9.4.5

- Expired current plans now show **Renew this plan** instead of the passive Current plan indicator.
- Renewal records the renewal time, resets the subscription start time, calculates a fresh expiry from the active live/test expiration setting, restores ACTIVE status, and writes a subscription history record.
- The admin overview fetches current merchant/subscription data every second without requiring a page reload.
- Added a general admin database search for IDs and searchable merchant, user, invoice, payment, feedback, audit-log, and subscription-change records.
- Existing v0.9.4.4 plan switching and test-mode behavior are retained.
