# MerchantPay v0.9.4.6.1

- Restored and verified merchant account controls from the prior working source: password change, accent theme selection, light/dark appearance selection, and business logo upload/removal.
- Merchant appearance is account-specific and remains isolated between accounts.
- Saved appearance and business identity now refresh every 2 seconds immediately after authentication and while the merchant remains logged in. The live brand/logo updates without requiring a manual visit to Settings.
- Kept the v0.9.4.5 renewal, expiration, plan-change history, test-mode expiration controls, admin real-time refresh, and general admin search behavior as the base rather than importing unrelated older payment code.
- Preserved the existing 0.9.4.5 source structure and did not merge the separate older legacy payment provider implementation because its schema/API assumptions are not present in the 0.9.4.5 source. legacy payment provider integration remains a separate payment milestone.

## Development notes

The project intentionally does not include `node_modules`. Run `npm install` before development.
