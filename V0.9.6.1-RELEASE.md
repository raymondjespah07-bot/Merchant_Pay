# MerchantPay v0.9.6.1 — Vercel Hobby-ready release

## Main change

Removed the minute-level Vercel Cron registration used by v0.9.6 for merchant payout release.

The secure payout release endpoint remains available at:

`GET /api/cron/release-payouts`

It is triggered by an external HTTP scheduler using `Authorization: Bearer <CRON_SECRET>`.

## Why

Vercel Hobby does not permit frequent Cron schedules. Keeping the minute-level Cron entry would make the project unsuitable for a Hobby deployment. v0.9.6.1 leaves `vercel.json` without a `crons` section while preserving the one-hour payout-hold logic.

## Included

- Paytota collection, payout, webhook and balance integration from v0.9.6.
- One-hour merchant payout hold.
- Protected external payout-release endpoint.
- Admin Money Center and manual payout.
- No frequent Vercel Cron configuration.

See `docs/PAYTOTA-V0.9.6.1-SETUP.md` for deployment and scheduler setup.
